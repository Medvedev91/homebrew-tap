# Option1 Homebrew Tap

```sh
brew install Medvedev91/tap/Option1
```

Casks for [Option1](https://github.com/Medvedev91/Option1) - Two new features for macOS:
1. Open apps with shortcuts, like ⌥-1 for Chrome, ⌥-2 for Slack;
2. Open projects with shortcuts, like ⌥-3 for Option1.xcodeproj in Xcode. Any app.

Documentation - https://github.com/Medvedev91/Option1
